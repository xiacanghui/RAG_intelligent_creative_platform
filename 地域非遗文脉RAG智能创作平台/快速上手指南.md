# 地域非遗文脉RAG智能创作平台 - 快速上手指南

## 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 |
| Python | 3.10 或更高版本 |
| 内存 | 16GB DDR4 |
| 显卡 | RTX4060 8G（支持CUDA加速） |
| 磁盘 | 至少 5GB 可用空间 |

## 一键启动（推荐）

### 方式一：双击启动
1. 双击运行 `一键启动.bat`
2. 等待自动安装依赖和启动服务
3. 打开浏览器访问 `http://localhost:8000`

### 方式二：命令行启动
```bash
# 1. 安装Python依赖
pip install -r requirements.txt

# 2. 拉取轻量化模型（首次运行）
python ollama_run.py

# 3. 启动平台
python main.py
```

## 轻量化模型说明

本平台采用 **deepseek-distill:1.5b** 轻量化蒸馏模型：
- **参数规模**: 1.5B（轻量化）
- **量化方式**: 4bit（显存占用低）
- **推理加速**: GPU CUDA
- **显存需求**: ~1.5GB
- **内存需求**: ~2GB
- **下载体积**: ~1GB
- **加载时间**: <10秒

## 模型切换

平台支持三种模型切换：

| 模型 | 类型 | 特点 |
|------|------|------|
| 本地 DeepSeek 蒸馏模型 | 本地 | 离线可用，响应快 |
| 智谱 GLM-4-Flash | 云端 | 免费，回答质量高 |
| 硅基流动 DeepSeek-R1 | 云端 | 推理能力强 |

在页面右上角点击"切换模型"按钮即可选择。

## 常见问题

**Q: Ollama显示未连接？**
A: 确保Ollama桌面应用已打开并在后台运行。如未安装，请先运行 `python ollama_run.py`。

**Q: 模型回答很慢？**
A: 本平台使用1.5b轻量化模型，正常情况下响应很快。如仍较慢，请检查：
1. GPU驱动是否正常
2. 显存是否充足（任务管理器查看）
3. 是否有其他程序占用显存

**Q: 如何切换到云端模型？**
A: 点击页面右上角"切换模型"，选择"智谱 GLM-4-Flash"或"硅基流动 DeepSeek-R1"。

**Q: 端口8000被占用？**
A: 修改 `.env` 文件中 `FASTAPI_PORT=8001`，然后访问 `http://localhost:8001`

## 项目结构

```
├─ main.py              # 后端主程序（单进程架构）
├─ model_switch.py      # 双模型调度控制器
├─ ollama_run.py        # Ollama一键拉取脚本
├─ rag_core.py          # RAG检索核心
├─ static/index.html    # 前端页面
├─ knowledge_base/      # 非遗知识库
├─ vector_store/        # 搜索索引
├─ .env                 # 配置文件
└─ requirements.txt     # 依赖清单
```

## 技术亮点

1. **轻量化本地推理**: 1.5b蒸馏模型，4bit量化，GPU加速
2. **双模型调度**: 本地优先，云端兜底，自动降级
3. **国内镜像加速**: ollama_run.py内置镜像配置，解决下载超时
4. **断点续传**: 模型下载支持中断后继续
5. **资源监控**: 实时显示内存、显存使用状态
